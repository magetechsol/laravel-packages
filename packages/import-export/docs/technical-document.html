MTS Laravel Import Export

Enterprise-grade import/export engine for Laravel with streaming, queue processing, and real-time progress tracking.

Production Ready PHP 8.2+ Laravel 11/12/13 68 Tests Passing

Overview

magetech/laravel-import-export is a streaming-first import/export engine designed for enterprise Laravel applications. It handles millions of rows without exhausting memory by processing data in configurable chunks through Laravel's queue system.

Core Problem Solved

Standard import packages load entire files into memory, causing OutOfMemoryError with large datasets. This package streams every row through generators, processes chunks via queued jobs, and tracks progress in real-time — making it safe for production imports of 10M+ rows.

Key Capabilities

📄 Multi-Format Streaming

CSV, XLSX (via openspout), JSON, and XML readers that never load the full file into memory. Each row is yielded as a PHP generator.

⚡ Queue-Based Processing

Chunked jobs dispatched to Redis/Database/SQS queues. Configurable chunk sizes, retry logic, and timeout controls.

📊 Real-Time Progress

Database-backed progress tracking with percentage, ETA, throughput (rows/sec), and event-driven updates for WebSocket integration.

🔒 Production Security

Formula injection protection, MIME validation, path traversal prevention, and configurable file size limits.

Import Data Flow

Import::make(Product::class)        // 1. Create Import builder
    ->from($file)                     // 2. Resolve file path
    ->map([...])                      // 3. Configure ColumnMapper
    ->validate([...])                 // 4. Configure RowValidator
    ->duplicateDetection('upsert')    // 5. Configure DuplicateDetector
    ->queue();                        // 6. Dispatch to queue

// Inside ProcessImportJob:
ReaderFactory::make($path)           // Creates CsvReader/XlsxReader/etc.
  ->rows()                           // Generator yields [rowNumber => data]
    ->chunkById(1000)                // Chunk into batches
      ->processRow()                 // Per-row pipeline:
        // 1. ColumnMapper::map()         → mapped data
        // 2. RowValidator::validate()    → errors or pass
        // 3. DuplicateDetector::check()  → skip/reject/upsert/continue
        // 4. TransformerPipeline::transform() → cleaned data
        // 5. Model::create() or updateOrCreate()
      ->ImportRow::update()          // Persist row status
    ->commit()                       // Commit chunk results
  ->Import::update()                 // Update progress counters
  ->markAsCompleted()                // Final status

Core Components

Readers

All readers implement ReaderInterface and return data as PHP generators. Each row is yielded as [int $rowNumber => array $data].

Reader Format Library Memory Profile
CsvReader CSV PHP native fgetcsv() ~1KB per row
XlsxReader XLSX openspout/openspout ~1KB per row
JsonReader JSON PHP native streaming ~1KB per row
XmlFileReader XML PHP XMLReader ~1KB per row

ReaderFactory

// Automatic detection by file extension
$reader = ReaderFactory::make($filePath);

// Supported extensions: csv, xlsx, xls, json, xml
$reader->open($filePath);

foreach ($reader->rows() as $rowNumber => $rowData) {
    // $rowData = ['name' => 'Widget', 'sku' => 'WGT-001', ...]
}

$reader->close();
$reader->totalRows(); // Returns total row count (excluding header)

XmlFileReader XPath Mapping

// XML structure: <products><product><name>...</product></products>
$reader = ReaderFactory::make($path);

// Configure XPath mappings via options
$reader->setRowXPath('//product');
$reader->setFieldXPaths([
    'name'   => 'name',
    'sku'    => 'sku',
    'price'  => 'price/amount',
    'weight' => 'dimensions/weight',
]);

All writers implement WriterInterface. They write data row-by-row without buffering the entire dataset.

WriterFactory

$writer->setHeaders(['name', 'sku', 'price']);
$writer->open($filePath);

foreach ($rows as $row) {
    $writer->write([$row]);

$writer->close();

Column Mapper

The ColumnMapper maps source CSV/Excel column names to your Eloquent model attributes. Supports flat mapping, nested dot-notation mapping, default values, and column skipping.

// Basic column mapping
Import::make(Product::class)
    ->from($file)
    ->map([
        'Product Name' => 'name',           // CSV header → model attribute
        'SKU Code'     => 'sku',
        'Unit Price'   => 'price',
        'Qty in Stock' => 'stock_quantity',
    ])
    ->defaults([
        'is_active' => true,                // Default value if missing
    ])
    ->skipColumns(['notes', 'internal_id']) // Skip these columns
    ->process();

Nested Mapping (Dot Notation)

->map([
    'First Name'  => 'author.name',
    'Email'       => 'author.email',
    'ISBN'        => 'metadata.isbn',
    'Published'   => 'metadata.published_at',
])
// Produces: ['author' => ['name' => '...', 'email' => '...'], 'metadata' => [...]]

Transformers

The TransformerPipeline processes data after mapping. It runs transforms in sequence: TypeCaster → Sanitizer → Custom transforms.

TypeCaster

Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->castTypes([
        'price'            => 'float',
        'stock_quantity'   => 'integer',
        'is_active'        => 'boolean',
        'metadata'         => 'array',
        'published_at'     => 'datetime',
    ])
    ->process();

Sanitizer (Formula Injection Protection)

Automatically prefixes cells starting with =, +, -, @ with a single quote to prevent CSV/Excel formula injection attacks.

// Enabled by default via config
'mts-import-export.security.formula_injection_protection' => true,

// Input: "=CMD('calc.exe')"  →  Output: "'=CMD('calc.exe')"
// Input: "+SUM(A1:A10)"      →  Output: "'+SUM(A1:A10)"
// Input: "Normal text"       →  Output: "Normal text" (unchanged)

Custom Transforms

Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->transform(function (array $row) {
        $row['name'] = strtoupper($row['name']);
        $row['sku'] = strtolower($row['sku']);
        $row['price'] = round($row['price'], 2);
        return $row;
    })
    ->process();

Duplicate Detector

Detects duplicates based on a unique key column. Supports three modes:

ModeBehaviorUse Case
ignore Skip duplicate rows silently Idempotent re-imports
reject Mark duplicate rows as failed Strict uniqueness enforcement
upsert Update existing, insert new Data synchronization / refresh 
// Ignore mode — skip duplicates
Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->duplicateDetection('ignore', 'sku')
    ->process();

// Upsert mode — update existing records
Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->duplicateDetection('upsert', 'sku')
    ->process();

Queue System

Queue Architecture

Import::make(Product::class)->from($file)->map([...])->queue();
    │
    ├── createImportRecord()           → INSERT INTO imports
    ├── ImportStatus::Queued           → UPDATE imports SET status='queued'
    └── ProcessImportJob::dispatch()   → Laravel Queue
         │
         ├── Importer::process()
         │    ├── ReaderFactory::make()     → Streaming reader
         │    ├── chunkById(1000)           → Chunk rows
         │    └── processChunk()
         │         ├── DB::beginTransaction()
         │         ├── processRow() × N     → Per-row pipeline
         │         ├── DB::commit()
         │         └── updateProgress()     → UPDATE imports
         │
         └── ImportCompleted event     → Dispatched on success

Queue Configuration

// config/queue.php — add an imports queue
'queues' => [
    'imports' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => env('MTS_IMPORT_QUEUE', 'imports'),
        'retry_after' => 90,
        'timeout' => 600,
        'max_jobs' => 0,
        'max_time' => 0,
    ],
],

// config/mts-import-export.php
'import' => [
    'queue_connection' => env('MTS_QUEUE_CONNECTION', 'redis'),
    'queue_name' => env('MTS_IMPORT_QUEUE', 'imports'),
    'chunk_size' => 1000,
    'timeout' => 600,
],

Running Workers

# Process imports queue
php artisan queue:work --queue=imports --timeout=600

# Process both imports and exports
php artisan queue:work --queue=imports,exports

# With Redis (recommended for production)
php artisan queue:work redis --queue=imports --timeout=600 --tries=3

use MageTech\ImportExport\Support\Facades\Import;

// ─── Build & Process ───

    ->withOptions([...])                   // Custom metadata
    ->process();                           // Sync execution

// ─── Queue for Async ───
$import = Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->queue();                             // Dispatch to queue

// ─── Result ───
$import->status;           // ImportStatus enum
$import->total_rows;       // int
$import->successful_rows;  // int
$import->failed_rows;      // int
$import->skipped_rows;     // int

Export Facade

use MageTech\ImportExport\Support\Facades\Export;

// ─── Build & Process ───
$export = Export::make(Product::class)
    ->to('products.xlsx')                  // Output file
    ->toDisk('s3')                         // Output disk
    ->columns(['name', 'sku', 'price'])    // Columns to export
    ->filter(fn($q) => $q->where('active', true))  // Query filter
    ->chunkSize(5000)                      // Rows per chunk
    ->process();

// ─── Queue for Async ───
$export = Export::make(Product::class)
    ->to('products.xlsx')
    ->columns([...])
    ->queue();

// ─── Result ───

$export->total_rows;      // int
$export->processed_rows;  // int

use MageTech\ImportExport\Events\ImportProgress;

Event::listen(ImportProgress::class, function ($event) {
    $import = $event->import;
    $percentage = round(($import->successful_rows + $import->failed_rows) / $import->total_rows * 100, 1);

Security

Security Features

🛡️ Formula Injection Protection

Sanitizes CSV/Excel cells starting with =, +, -, @ by prefixing with a single quote. Prevents spreadsheet formula attacks.

🔍 MIME Validation

Uses finfo to verify actual file MIME type, not just extension. Prevents malicious file uploads disguised as CSV.

📁 Path Traversal Prevention

Validates all file paths with realpath() to prevent ../../etc/passwd style attacks.

📏 File Size Limits

Configurable maximum upload size. Rejects files exceeding the limit before processing begins.

// config/mts-import-export.php
'security' => [
    'formula_injection_protection' => true,
    'allowed_mime_types' => [
        'text/csv',
        'text/plain',
        'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
        'application/json',
        'text/xml',
        'application/xml',
    ],
    'max_file_size' => 52428800, // 50MB
],
