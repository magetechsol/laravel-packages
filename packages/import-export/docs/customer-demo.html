How It Works

3 Steps to Your First Import

Getting started takes less than 5 minutes. Here's how it works end-to-end.

1

Install & Configure

Run one Artisan command to publish config, migrations, and seed data. Run php artisan migrate.

2

Build Your Import

Use the Import facade to define your mapping, validation, and duplicate handling. 5 lines of code.

3

Process or Queue

Call ->process() for sync, or ->queue() for async. Monitor progress with events.

app/Http/Controllers/ImportController.php 
use MageTech\ImportExport\Support\Facades\Import;

public function store(Request $request)
{
    // Validate the uploaded file
    $request->validate([
        'file' => 'required|file|mimes:csv,xlsx|max:51200',
    ]);

    // Import with 5 lines of code
    $import = Import::make(Product::class)
        ->from($request->file('file'))
        ->map([
            'Product Name' => 'name',
            'SKU'          => 'sku',
            'Price'        => 'price',
            'Stock'        => 'stock_quantity',
        ])
        ->validate([
            'name'  => ['required', 'string'],
            'sku'   => ['required', 'unique:products,sku'],
            'price' => ['required', 'numeric', 'min:0'],
        ])
        ->duplicateDetection('upsert', 'sku')
        ->queue();  // Async processing

    return response()->json([
        'message' => 'Import queued successfully',
        'import_id' => $import->id,
    ]);
}
Features

Everything You Need

Built-in features that solve real production challenges.

Intelligent Column Mapping

Your Excel file has different column names than your database? No problem. Map any source column to any model attribute.

  • Map CSV headers to Eloquent attributes
  • Nested dot-notation for JSON columns
  • Default values for missing columns
  • Skip unwanted columns entirely
// Excel has "Product Name", DB has "name"
->map([
    'Product Name'  => 'name',
    'SKU Code'      => 'sku',
    'Unit Price'    => 'price',
    'Category'      => 'category.name',
])
->defaults([
    'is_active' => true,
])
->skipColumns(['notes', 'internal_id'])

Smart Duplicate Detection

Choose how to handle duplicates based on your business rules. Three modes for three scenarios.

  • Ignore: Skip existing records silently
  • Reject: Mark duplicates as errors
  • Upsert: Update existing, insert new
  • Works with any unique column combination
// Idempotent re-import — skip what exists
->duplicateDetection('ignore', 'sku')

// Update existing products with new data
->duplicateDetection('upsert', 'sku')

// Fail on any duplicate
->duplicateDetection('reject', 'sku')

// Works with composite keys too
->duplicateDetection('upsert', 'email')

Multi-Level Validation

Catch errors before they corrupt your data. Validate at file level AND row level.

  • File type and size validation
  • Row-level Laravel validation rules
  • Per-column error tracking
  • Downloadable error reports (CSV/XLSX)
// Use standard Laravel rules
->validate([
    'name'  => ['required', 'string'],
    'email' => ['required', 'email'],
    'age'   => ['nullable', 'integer', 'min:18'],
    'price' => ['required', 'numeric', 'min:0'],
])

// Failed rows get detailed error messages
// Row 5: "email" must be a valid email address
// Row 12: "price" must be at least 0

Queue-Based Processing

Large imports don't block your app. Queue them and let your workers process in the background.

  • Redis, Database, SQS-compatible queues
  • Configurable chunk sizes (500-5000 rows)
  • Automatic retry for failed jobs
  • Real-time progress via events
  • Cancel running imports
  • Retry failed rows independently
// Queue for background processing
$import = Import::make(Product::class)
    ->from($file)
    ->map([...])
    ->queue();  // ← That's it!

// Listen for progress updates
Event::listen(ImportProgress::class, function ($e) {
    $pct = round(
        ($e->import->successful_rows
       + $e->import->failed_rows)
       / $e->import->total_rows * 100
    );
    // Broadcast to WebSocket, update UI...
});

Production-Grade Security

Built-in protections against common attack vectors in file imports.

  • Formula injection protection (prevents =CMD() attacks)
  • MIME type verification (not just file extension)
  • Path traversal prevention
  • Configurable file size limits
  • Filename sanitization
// Formula injection — what attackers try:
=CMD('calc.exe')     // Windows command
=SUM(A1:A100)       // Data exfiltration
+cmd|'/c calc'!A0   // Shell injection
@SUM(A1:A100)       // Hidden formula

// What the sanitizer does:
'=CMD('calc.exe')   // Neutralized
'+SUM(A1:A100)     // Safe text
'+cmd|'/c calc'!A0  // Safe text
'@SUM(A1:A100)      // Safe text

Data Transformation Pipeline

Clean and transform data before it hits your database. Built-in type casting, sanitization, and custom transforms.

  • Automatic type casting (int, float, bool, array, datetime)
  • Formula injection sanitization
  • Custom transform callbacks
  • Pipeline runs in sequence: cast → sanitize → custom
// Type casting — auto-converts strings
->castTypes([
    'price'          => 'float',
    'stock_quantity' => 'integer',
    'is_active'      => 'boolean',
    'metadata'       => 'array',
])

// Custom transform — your own logic
->transform(function ($row) {
    $row['name'] = ucfirst($row['name']);
    $row['sku'] = strtoupper($row['sku']);
    $row['price'] = round($row['price'], 2);
    return $row;
})
Export

Export Any Data to Any Format

One-liner exports with query filters, column selection, and queue support.

Export with filters and custom columns 
use MageTech\ImportExport\Support\Facades\Export;

// Quick export to CSV
Export::make(Product::class)
    ->to('products.csv')
    ->columns(['name', 'sku', 'price', 'stock_quantity'])
    ->process();

// Filtered export to XLSX with queue
Export::make(Order::class)
    ->to('q4-orders.xlsx')
    ->columns(['id', 'customer', 'total', 'status'])
    ->filter(function ($query) {
        return $query
            ->where('status', 'completed')
            ->whereBetween('created_at', ['2026-10-01', '2026-12-31']);
    })
    ->chunkSize(5000)
    ->queue();  // Background processing

Integration

Real-Time Progress with Events

Listen to import/export events to build real-time dashboards, send notifications, or trigger webhooks.

Event-driven progress tracking 
use MageTech\ImportExport\Events\ImportStarted;
use MageTech\ImportExport\Events\ImportProgress;
use MageTech\ImportExport\Events\ImportCompleted;
use MageTech\ImportExport\Events\ImportFailed;

// In EventServiceProvider::$listen:
$listen = [
    ImportProgress::class => [
        SendProgressNotification::class,
    ],
    ImportCompleted::class => [
        NotifyUserOfCompletion::class,
    ],
    ImportFailed::class => [
        AlertAdminOfFailure::class,
    ],
];

// Or listen inline:
Event::listen(ImportProgress::class, function ($event) {
    $import = $event->import;
    $progress = ($import->successful_rows + $import->failed_rows)
               / $import->total_rows * 100;

    Log::info("Import {$import->id}: {$progress}% complete");
});

Get Started

Install in 3 Commands

Terminal

composer require magetech/laravel-import-export

# 2. Publish config & migrations, run migrate
php artisan mts:import-export:install

# 3. Start your queue worker
php artisan queue:work --queue=imports
