# Contributing

Thank you for considering contributing to MTS Laravel Feature Flags!

## Code Style

- Use Laravel Pint for code formatting: `composer format`
- Follow PSR-12 coding standards
- Use `declare(strict_types=1)` in all PHP files
- Write meaningful commit messages

## Testing

- Write tests for all new features and bug fixes
- Run the full test suite before submitting: `composer test`
- Aim for high test coverage
- Use Pest PHP syntax

## Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Add or update tests as needed
5. Run tests and code style checks
6. Submit a pull request

## Reporting Issues

- Use the GitHub issue tracker
- Include steps to reproduce
- Include PHP and Laravel versions
- Include error messages if applicable
