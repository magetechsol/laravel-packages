# MTS Laravel SaaS Tenancy

Multi-tenant architecture for Laravel SaaS applications.

## Installation

```bash
composer require magetech/laravel-saas-tenancy
php artisan mts:saas-tenancy:install
```

## Requirements

- PHP 8.2+
- Laravel 11.x, 12.x, or 13.x
