MTS Laravel Query Toolkit

v1.0.0 MTS License

Enterprise-grade query builder for Laravel APIs with filtering, sorting, searching, pagination, and relationship support.

Package: magetech/laravel-query-toolkit
Namespace: MageTech\QueryToolkit

Requirements

  • PHP 8.3+
  • Laravel 12.x or 13.x
  • MySQL 8+, PostgreSQL 15+, or SQLite

Installation

bash
composer require magetech/laravel-query-toolkit
php artisan mts:query:install

Filter Examples

php - Exact Filter
// URL: /api/users?filter[name]=John
$users = QueryBuilder::for(User::class, $request)
    ->allowedFilters([
        AllowedFilter::exact('name'),
    ])
    ->get();
php - Numeric Filter
// URL: /api/products?filter[price][gte]=1000&filter[price][lte]=5000
$products = QueryBuilder::for(Product::class, $request)
    ->allowedFilters([
        AllowedFilter::gte('price'),
        AllowedFilter::lte('price'),
    ])
    ->get();
php - Relationship Filter
// URL: /api/users?filter[posts][is_published]=true
$users = QueryBuilder::for(User::class, $request)
    ->allowedFilters([
        AllowedFilter::relationship(
            'posts',
            'is_published',
            BooleanFilter::make('is_published')
        ),
    ])
    ->get();

Sorting

Supports single and multi-field sorting with direction control. Use - prefix for descending.

php
// URL: /api/users?sort=-name,created_at
$users = QueryBuilder::for(User::class, $request)
    ->allowedSorts(['name', 'created_at'])
    ->get();

// Generates: ORDER BY name DESC, created_at ASC

// Apply default sort
$users = QueryBuilder::for(User::class, $request)
    ->allowedSorts(['name', 'created_at'])
    ->applyDefaultSort('created_at', 'desc')
    ->get();

Search

Two search drivers: LIKE (default) and Full-Text (MySQL/PostgreSQL).

php - LIKE Search
// URL: /api/users?search=john
$users = QueryBuilder::for(User::class, $request)
    ->searchable(['name', 'email'])
    ->get();

// Generates: WHERE (name LIKE '%john%' OR email LIKE '%john%')
php - Full-Text Search
$products = QueryBuilder::for(Product::class, $request)
    ->searchable(
        ['name', 'description'],
        SearchDriver::FullText
    )
    ->get();

Relationship Includes

Supports eager loading, count includes, and custom includes.

php
// URL: /api/users?include=posts,roles
$users = QueryBuilder::for(User::class, $request)
    ->allowedIncludes(['posts', 'roles'])
    ->get();

// Count includes
$users = QueryBuilder::for(User::class, $request)
    ->allowedIncludes([
        AllowedInclude::key('posts'),
        AllowedInclude::count('posts_count', 'posts'),
    ])
    ->get();

Pagination

Standard and cursor pagination with configurable limits.

php
// URL: /api/users?page=2&per_page=25
$result = QueryBuilder::for(User::class, $request)
    ->allowedFilters(['name', 'status'])
    ->allowedSorts(['name', 'created_at'])
    ->paginate();

// Cursor pagination
$result = QueryBuilder::for(User::class, $request)
    ->useCursorPagination('id')
    ->paginate();

Security

Security Model: All filters, sorts, includes, and fields must be explicitly whitelisted.

Security Features

  • Whitelist-only filtering: Only explicitly allowed filters can be executed
  • SQL injection prevention: All queries use parameterized statements
  • Relationship validation: Related models must be in allowed list
  • Pagination limits: Max page size prevents abuse
  • Query complexity limits: Max filters/sorts/includes per request
