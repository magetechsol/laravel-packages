MTS Laravel API Toolkit

v1.0.0 MTS License

Standardized enterprise API responses, errors, and API architecture for Laravel applications.

Package: magetech/laravel-api-toolkit
Namespace: MageTech\ApiToolkit

Requirements

  • PHP 8.3+
  • Laravel 13.x

Installation

bash
composer require magetech/laravel-api-toolkit
php artisan mts:api:install

Architecture

The package follows a modular architecture with clear separation of concerns.

Response System

Standardized API response format with configurable envelope.

Response Envelope: When enabled, all responses follow the structure: {success, message, data, meta}

Success Responses

ApiResponse::success(mixed $data = null, string $message = 'Success', int $code = 200): JsonResponse
ApiResponse::created(mixed $data = null, string $message = 'Created'): JsonResponse
ApiResponse::noContent(string $message = 'No Content'): JsonResponse
php
// Basic success response
return ApiResponse::success(
    data: $users,
    message: 'Users retrieved successfully'
);

// Created response
return ApiResponse::created(
    data: $user,
    message: 'User created successfully'
);

// No content response
return ApiResponse::noContent('User deleted');
json - Response
{
    "success": true,
    "message": "Users retrieved successfully",
    "data": [...],
    "meta": {
        "request_id": "req_abc123def456",
        "correlation_id": "corr_xyz789",
        "api_version": "v1",
        "timestamp": "2026-08-24T12:00:00Z"
    }
}

Error Responses

ApiResponse::error(string $message, int $code = 400, ?string $errorCode = null, mixed $data = null): JsonResponse
ApiResponse::unauthorized(string $message = 'Unauthorized'): JsonResponse
ApiResponse::forbidden(string $message = 'Forbidden'): JsonResponse
ApiResponse::notFound(string $message = 'Not Found'): JsonResponse
ApiResponse::conflict(string $message = 'Conflict'): JsonResponse
ApiResponse::throttle(int $retryAfter = 60, string $message = 'Too Many Requests'): JsonResponse
ApiResponse::serverError(string $message = 'Internal Server Error'): JsonResponse
php
// Bad request
return ApiResponse::error(
    message: 'Invalid request parameters',
    code: 400,
    errorCode: 'BAD_REQUEST'
);

// Unauthorized
return ApiResponse::unauthorized('Please login');

// Not found
return ApiResponse::notFound('User not found');

// Rate limited
return ApiResponse::throttle(retryAfter: 30);
json - Error Response
{
    "success": false,
    "message": "The given data was invalid.",
    "error": {
        "code": "VALIDATION_ERROR",
        "type": "validation",
        "message": "The given data was invalid.",
        "details": {
            "email": ["The email field is required."]
        }
    },
    "meta": {
        "request_id": "req_abc123",
        "timestamp": "2026-08-24T12:00:00Z"
    }
}

Paginated Responses

ApiResponse::paginated(LengthAwarePaginator $paginator, string $message = 'Success'): JsonResponse
php
$users = User::paginate(15);

return ApiResponse::paginated(
    paginator: $users,
    message: 'Users retrieved successfully'
);
json - Paginated Response
{
    "success": true,
    "message": "Users retrieved successfully",
    "data": [...],
    "meta": {
        "pagination": {
            "current_page": 1,
            "per_page": 15,
            "total": 100,
            "last_page": 7,
            "links": {
                "first": "/api/v1/users?page=1",
                "last": "/api/v1/users?page=7",
                "prev": null,
                "next": "/api/v1/users?page=2"
            }

}

Resource Responses

ApiResponse::resource(JsonResource $resource, string $message = 'Success', int $code = 200): JsonResponse
ApiResponse::collection(array|iterable $collection, string $message = 'Success', int $code = 200): JsonResponse
php
// Single resource
return ApiResponse::resource(
    new UserResource($user),
    'User retrieved'
);

// Collection
return ApiResponse::collection(
    UserResource::collection($users),
    'Users retrieved'
);

Validation Error Responses

ApiResponse::validation(ValidationException $exception): JsonResponse
php
try {
    // Validation logic
} catch (ValidationException $e) {
    return ApiResponse::validation($e);
}

Security

Production Safety: Stack traces and sensitive exception information are never exposed in production.

Security Features

  • No stack traces: Hide stack traces in production mode
  • Secure IDs: Generate cryptographically secure request/correlation IDs
  • Exception mapping: Map exceptions to generic error messages
  • CORS support: Configurable CORS headers
  • Rate limiting: Built-in rate limit headers support
