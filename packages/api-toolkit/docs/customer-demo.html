Frequently Asked Questions

Everything you need to know

How long does it take to set up?
Less than 3 minutes! Run composer require, publish the config, add middleware, and start using ApiResponse in your controllers.
Does it work with existing Laravel projects?
Yes! The package is designed to work alongside your existing code. You can adopt it incrementally, one controller at a time.
Is it secure?
Absolutely. Stack traces are hidden in production, exceptions are mapped to generic errors, and secure request IDs are generated automatically.
Can I customize the response format?
Yes! You can disable the response envelope, customize headers, configure versioning, and even override the exception handler.
Does it support API versioning?
Yes! Three strategies: URL prefix (/api/v1/users), header (X-API-Version: v1), or query parameter (?api_version=v1).
What about performance?
The package is lightweight and adds minimal overhead. It uses Laravel's built-in response types and doesn't add database queries.
Can I use it with API Resources?
Yes! The ApiResponse::resource() and ApiResponse::collection() methods work perfectly with Laravel API Resources.
Is there documentation?
Yes! We provide comprehensive documentation including technical architecture docs, this customer guide, and a complete API reference.
